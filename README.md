# Board Node Java

Java와 Node.js를 비교 분석하기 위한 간단한 게시판 프로젝트입니다.

## 프로젝트 구조

- **프론트엔드**: Next.js
- **BFF (Backend for Frontend)**: Next.js
- **백엔드**: 
  - Java (Spring Boot)
  - Nest.js
- **데이터베이스**: PostgreSQL
- **인증**: Supabase

## 목적

Node.js가 뭔지 좀 알아보고자 만든 개인 프로젝트입니다.

## 주요 기능

- 사용자 인증 (Supabase)
- 게시글 CRUD
- 댓글 기능
- 파일 업로드

## 기술 스택 비교 포인트

1. **개발 생산성**
   - Java vs Node.js의 개발 속도
   - 코드 구조와 패턴
   - 타입 시스템

2. **성능**
   - 동시 처리 능력
   - 메모리 사용량
   - 응답 시간

3. **확장성**
   - 마이크로서비스 아키텍처 적용
   - 모듈화
   - 배포 전략

4. **유지보수성**
   - 코드 가독성
   - 테스트 용이성
   - 디버깅
